# AWS EC2 Static Website Hosting

## Project Overview

A personal hands-on project exploring static website hosting on Amazon EC2 using a Linux-based instance.

## Objectives

- Understand AWS EC2 instance setup.
- Configure SSH access using EC2 key pairs.
- Configure security groups to control network access.
- Install and configure a web server.
- Deploy and verify a static website.
- Create an Amazon S3 bucket for storage practice.

## AWS Services and Technologies

- Amazon EC2
- Amazon S3
- Linux
- SSH
- EC2 Key Pairs
- AWS Security Groups

## Implementation Steps

1. Selected an Amazon Machine Image (AMI) and launched a Linux EC2 instance.
2. Configured the EC2 key pair and security group.
3. Connected to the instance using SSH.
4. Installed and configured a web server.
5. Deployed and verified the static website using the EC2 public IP address.
6. Created an Amazon S3 bucket for storage practice.

## Key Learnings

- EC2 instance provisioning and configuration.
- Linux server access using SSH.
- Network access control through security groups.
- Basic web server setup and website deployment.
- Fundamentals of Amazon S3 storage.
